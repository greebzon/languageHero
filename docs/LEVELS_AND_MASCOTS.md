# Уровни и друзья

Реализовано 19 сентября 2026. Один ребёнок — один аккаунт, общий опыт и уровень для всех изучаемых языков. Уровень отражает участие в занятиях; освоение слов и тем показывается отдельно в статистике.

## Опыт и уровни

Первое завершение урока даёт 100 XP и 30 монет. Ошибки не уменьшают XP. Повторное прохождение, новая версия того же урока и повторная отправка результатов не дают награду снова. Дополнительный опыт за ежедневные повторения и монеты за повышение уровня пока не вводятся.

| Уровень | Всего XP для достижения |
| ------- | ----------------------- |
| 1       | 0                       |
| 2       | 100                     |
| 3       | 300                     |
| 4       | 600                     |
| 5       | 1000                    |
| 6       | 1500                    |
| 7       | 2000                    |
| 8       | 2500                    |

После пятого уровня каждый переход стоит 500 XP. Уровень не падает от пропусков, ошибок или смены языка. Сеты открываются по учебному маршруту независимо от уровня аккаунта.

## Галерея «Мои друзья»

Галерея открывается с главной, из профиля и бокового меню. Ребёнок видит опубликованных персонажей, рассматривает их в крупном предпросмотре и выбирает одного активного спутника кнопкой «Взять с собой». Закрытые персонажи показывают требуемый уровень; ближайшее открытие — оставшийся опыт. Выбранный персонаж отмечен «С тобой».

Начальные пороги:

| Маскот                   | Уровень открытия |
| ------------------------ | ---------------- |
| Лисёнок Тим (`fox`)      | 1                |
| Зайка Луна (`rabbit`)    | 3                |
| Медвежонок Балу (`bear`) | 5                |
| Совёнок Умка (`owl`)     | 8                |

Тим доступен всегда. Порог других персонажей задаётся в админке полем «Уровень открытия». Открытие бесплатно и постоянно; покупки за монеты относятся к гардеробу. Маскоты не дают преимуществ в проверке ответов или начислении опыта.

Выбранный друг сопровождает ребёнка на главной, в уроке и на результате. Повышение уровня и новые открытия показываются после подтверждения сервером; персонаж сам не переключается. Выбор сохраняется в аккаунте и доступен на других устройствах. При отсутствии связи галерея использует кэш, а смена спутника требует успешного ответа сервера. Общий образ, инвентарь и учебный прогресс сохраняются при смене персонажа.

## Хранение и совместимость

- `packages/learning-core/src/levels.ts` — пороги опыта и начальные уровни маскотов.
- `mascots.unlock_level` — редактируемый порог; публичный каталог содержит `unlockLevel`.
- `learner_mascots` — постоянные открытия по аккаунту и ID маскота. Повторное подтверждение не создаёт дубль. Снятие с публикации скрывает персонажа из публичного каталога, но не удаляет запись открытия.
- `AccountProfile.unlockedMascotIds` — подтверждённые открытия; клиент не может записать уровень, опыт или этот список через API профиля.
- `learner_accounts.avatar` — единственный активный спутник. Сервер проверяет доступ при `PATCH /v1/account/me`.
- `learner_accounts.level_floor` сохраняет достигнутый уровень. Миграция `0009_mascot_levels.sql` сохраняет выбранных персонажей существующих аккаунтов; при первом чтении их прежний уровень вычисляется через старый `ACCOUNT_LEVEL_STEP` и не понижается. Эта настройка теперь нужна только для перехода со старой системы. Если опыт ниже нового порога сохранённого уровня, следующий уровень требует достижения нового общего порога XP.
- Перед повышением порога или снятием опубликованного маскота с публикации сервер фиксирует доступ всех уже подходящих аккаунтов, включая тех, кто сейчас офлайн.

Перед запуском обновлённого API выполнить `pnpm db:migrate`. Миграция не сбрасывает опыт, уроки, монеты или образ. Интерфейс галереи переведён на русский, английский и иврит.
