# ADR 0001. Хранилище и стек админ-панели

Дата: 18 сентября 2026. Статус: принято, этапы A–B реализованы.

## Решения

- **PostgreSQL 17 в Docker** (`docker-compose.yml`, порт 5433) — редакторские данные, сессии,
  журнал изменений и история выпусков. Postgres выбран сразу (а не SQLite) ради транзакционных
  lease будущего worker'а и совместимости с несколькими серверами.
- **Drizzle ORM + `pg`**, миграции генерируются `drizzle-kit generate` в `apps/api/drizzle/` и
  применяются `pnpm db:migrate`. Схема в `apps/api/src/db/schema.ts` — единственный источник
  структуры; публичный JSON-формат каталога и пакетов от ORM не зависит.
- **Публичный `content/store` остаётся источником истины для приложения.** База — только для
  черновиков. Публикация собирает полный `Release` из базы и отдаёт его существующему
  `publishRelease` (`apps/api/src/content.ts`), который проверяет и атомарно переключает каталог.
- **Пароли — `scrypt` из `node:crypto`**, сессии — случайный токен, в базе только его SHA-256,
  клиенту HttpOnly-cookie `lh_admin` (`SameSite=Lax`, `Secure` по `ADMIN_COOKIE_SECURE`).
  Нативных модулей (argon2/bcrypt) нет намеренно: workspace использует hoisted-линкер и Windows.
- **Панель на том же origin, что и API.** Dev — Vite-proxy `/v1 → 127.0.0.1:3001` без
  `changeOrigin`; production — `@fastify/static` раздаёт `apps/admin/dist` под `/admin/`. CSRF
  закрывается проверкой заголовка `Origin` на всех не-GET запросах (или точным `ADMIN_ORIGIN`).
  `Access-Control-Allow-Origin: *` действует только на публичные маршруты каталога.
- **Черновые файлы** живут в `ADMIN_STORAGE_ROOT` (`.data/drafts`) и копируются в
  `content/store/media` только при публикации. Файлы адресуются SHA-256 после проверки содержимого.
- **Тесты с базой** создают отдельную базу на запуск (`createTestDatabase`): сгенерированные
  миграции ссылаются на `"public"."table"`, поэтому изоляция через `search_path` невозможна.

## Последствия

- Для разработки нужен запущенный Docker Desktop; без `DATABASE_URL` API работает как раньше
  (только публичные маршруты), панель недоступна.
- Порядок сетов/уроков хранится в `position` без unique-индекса — перестановка переписывает
  позиции в одной транзакции.
- Патч-схемы в `packages/contracts/src/admin.ts` собраны из полей без `.default()`: в zod 4
  `.partial()` сохраняет значения по умолчанию и иначе сбрасывал бы непереданные поля.
