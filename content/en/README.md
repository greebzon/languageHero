# Английский: первая тема

Пять уроков `en-animals-01` … `en-animals-05`, 23 задания трёх типов, четыре слова: fox, bear, rabbit, owl. Исходный выпуск — `content/seed.json`; опубликованные версии — `content/store/lessons`.

Схема — `courseLessonSchema`, версия 2. Каталог не содержит ключей ответов; самодостаточные пакеты уроков содержат данные локальной проверки. Публикация и добавление новых языков описаны в `docs/CONTENT.md`. Прежний `src/demo/lesson.ts` сохранён как материал демоверсии; приложение работает с новым каталогом.

В папке `content/assets-manifest` указано происхождение иллюстраций, шрифтов и озвучки.
